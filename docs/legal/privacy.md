# Podcast Studio – Privacy Policy

_Last updated: 25 October 2026_

Podcast Studio is a personal tool that publishes the operator's own podcast clips to the
operator's own TikTok account. It is used only by its operator (Hanh Le).

**Data we access.** When the operator connects TikTok, Podcast Studio receives an OAuth access
token, a refresh token and the account's open ID, and reads basic account information
(display name, allowed privacy settings) needed to publish videos.

**How it is used.** The tokens are used only to upload the operator's own videos to the
operator's own TikTok account and to check the upload status.

**Storage.** Tokens are stored locally on the operator's own computer. They are not sold,
shared with or sent to any third party other than TikTok's API.

**Other users.** Podcast Studio does not collect any data about other TikTok users or viewers.

**Deletion.** The operator can revoke access at any time in TikTok (Settings and privacy →
Security → Manage app permissions); the local token file can be deleted at the same time.
